# E SE VOCÊ TIVESSE DEPENDÊNCIA EMOCIONAL EM UM RELACIONAMENTO TÓXICO? — Contos Épicos

Animação 2D original (90 s, 1080×1920, 30 fps, sem áudio). Personagens: Lucas e Sofia.

- `dependencia_sem_legenda.mp4` / `dependencia_com_legenda.mp4` / `dependencia.srt`
- `PROMPT_NARRACAO_E_SOM.md` — prompt para gerar narração, música e efeitos.
- `projeto/` — código da animação (`node render.js --legendas 0|1`).

Metáfora visual: o suéter mostarda de Lucas vai perdendo a cor conforme ele se perde; no espelho, o reflexo está quase cinza e transparente. No final a cor volta só um pouco — recuperar a identidade é um processo.
