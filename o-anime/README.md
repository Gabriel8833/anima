# E SE VOCÊ ACHASSE QUE ESTAVA EM UM ANIME? — Contos Épicos

Animação 2D original (90 s, 1080×1920, 30 fps, sem áudio), protagonista Renan.

- `anime_sem_legenda.mp4` / `anime_com_legenda.mp4` / `anime.srt`
- `PROMPT_NARRACAO_E_SOM.md` — prompt para gerar narração, música e efeitos.
- `projeto/` — código da animação (`node render.js --legendas 0|1`).

Imaginação (etiqueta "NA CABEÇA DELE"): fundos com raios, linhas de velocidade, auras, olhos brilhando, nomes de golpes.
Realidade (etiqueta "NA VIDA REAL"): cenários comuns, sem efeitos. A cena final só sugere o disparo com corte para preto (sem violência gráfica).
