# E SE VOCÊ SENTISSE UM VAZIO QUE NÃO CONSEGUE EXPLICAR? — Contos Épicos

Animação 2D original (90 s, 1080×1920, 30 fps, sem áudio).

- `vazio_sem_legenda.mp4` / `vazio_com_legenda.mp4` / `vazio.srt`
- `PROMPT_NARRACAO_E_SOM.md` — prompt para gerar narração, música e efeitos.
- `projeto/` — código da animação (`node render.js --legendas 0|1`).

Motivo visual: o contorno de uma peça de quebra-cabeça vazia no peito. Ela não some no final; passa a ser iluminada por dentro (esperança realista).
