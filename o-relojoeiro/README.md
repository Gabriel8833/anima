# E SE VOCÊ FOSSE O RELOJOEIRO? — Contos Épicos

História **original** (90 s, 2D, 1080×1920, 30 fps, sem áudio, clima de drama criminal no deserto com filtro amarelado), criada no lugar do pedido "E se você fosse Walter White?", com a mesma jornada: homem comum → crise → oportunidade → primeira decisão → transformação → o preço do poder. Nenhuma cena, nome ou diálogo da série é reproduzido e não há nenhuma instrução real de crime.

- `relojoeiro_sem_legenda.mp4` / `relojoeiro_com_legenda.mp4` / `relojoeiro.srt`
- `PROMPT_NARRACAO_E_SOM.md` — prompt para gerar narração, música e efeitos.
- `projeto/` — código da animação (`node render.js --legendas 0|1`).
