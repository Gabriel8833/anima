# GABRIEL GANLEY — UM SONHO QUE DEIXOU SUA MARCA — Contos Épicos

Homenagem em animação 2D (2:00, 1080×1920, 30 fps, sem áudio). Representação estilizada e respeitosa, sem diálogos inventados, sem imagens médicas e sem encenar a morte. A causa citada é a informada pela imprensa a partir do atestado de óbito.

- `ganley_sem_legenda.mp4` / `ganley_com_legenda.mp4` / `ganley.srt`
- `PROMPT_NARRACAO_E_SOM.md` — prompt para gerar narração, música e efeitos.
- `projeto/` — código da animação (`node render.js --legendas 0|1`).
