# VOCÊ JÁ SE PERGUNTOU POR QUE O TETO DO CARRO TEM UMA ANTENA? — Contos Épicos

Animação 3D estilizada (Three.js, visual de desenho com sombreamento toon e contorno), 55 s, 1080×1920, 30 fps, sem áudio.

- `antena_sem_legenda.mp4` / `antena_com_legenda.mp4` / `antena.srt`
- `PROMPT_NARRACAO_E_SOM.md` — prompt para gerar narração, música e efeitos.
- `projeto/` — código (`node render.js --legendas 0|1`; precisa do pacote `three@0.170.0`, via `--modules <pasta node_modules>`).
