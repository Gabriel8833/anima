# IMAGINE TER UM IRMÃO QUE É UM ENCOSTO PROFISSIONAL — Contos Épicos

Animação 3D (≈1min14s, 1080×1920, 30 fps).

- `encosto_com_narracao_guia.mp4` — vídeo com a narração-guia sintética (MBROLA, gerada localmente; voz robótica, serve de referência de tempo)
- `encosto_sem_audio.mp4` — vídeo sem áudio, para usar a voz de outro aplicativo
- `encosto_narracao_guia.wav` / `encosto.srt`
- `PROMPT_NARRACAO_E_SOM.md` — narração, vozes (tempos exatos), música e efeitos.
- `projeto/` — código (`python3 voz.py` gera a voz e os tempos; `node render.js` gera o vídeo).
