# A PRISÃO DENTRO DE VOCÊ — Contos Épicos

Animação 2D original (90 s, 1080×1920, 30 fps, sem áudio), com o mesmo clima e os mesmos temas pedidos (vida vazia, consumismo, um "outro" que assume o controle, revelação no espelho), mas sem personagens, nomes ou cenas de nenhum filme.

- `prisao_sem_legenda.mp4` / `prisao_com_legenda.mp4` / `prisao.srt`
- `PROMPT_NARRACAO_E_SOM.md` — prompt para gerar narração, música e efeitos.
- `projeto/` — código da animação (`node render.js --legendas 0|1`).
