# E SE VOCÊ TIVESSE EGO DEMAIS? — Contos Épicos

Animação 2D original (90 s, 1080×1920, 30 fps, sem áudio).

- `ego_sem_legenda.mp4` / `ego_com_legenda.mp4` / `ego.srt`
- `PROMPT_NARRACAO_E_SOM.md` — prompt para gerar narração, música e efeitos.
- `projeto/` — código da animação (`node render.js --legendas 0|1`).

Metáfora visual: uma coroa dourada (o ego) que cresce a cada cena e fica pesada. No espelho, o reflexo muda primeiro e ele tira a coroa e a deixa na pia. No final ele manda uma mensagem pedindo desculpas, sem mostrar resposta (final aberto).
