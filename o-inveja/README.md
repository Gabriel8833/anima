# A VITÓRIA DO OUTRO — Contos Épicos

Animação 2D original (90 s, 1080×1920, 30 fps, sem áudio) sobre desigualdade, comparação e inveja. Personagens: Lucas (camisa polo azul) e Rafael (boné e camiseta vermelhos).

- `vitoria_sem_legenda.mp4` / `vitoria_com_legenda.mp4` (palavras-chave destacadas em amarelo) / `vitoria.srt`
- `PROMPT_NARRACAO_E_SOM.md` — prompt para gerar narração, música e efeitos.
- `projeto/` — código da animação (`node render.js --legendas 0|1`).
